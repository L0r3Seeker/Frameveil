FRAMEVEIL / STUDIO 0.2.0

帧幕，让素材成为画面。

图片、多图轮播、视频 · Windows x64 · 本地处理 · 无需配置开发环境

第一次使用 · Windows 11

  1. 完整解压压缩包，双击 Frameveil.exe。请保留旁边的 _internal 文件夹。
  2. 点击右侧 摄像头组件管理 → 安装 / 修复 Windows 原生组件，在 Windows 管理员授权弹窗点击“是”。首次注册需要授权。
  3. 向下滚动右侧参数区，点击 应用会议兼容预设，采用原生 720p / 30 FPS。
  4. 导入图片或视频，检查预览，再点击 开启虚拟摄像头。
  5. 重新打开微信或钉钉的摄像头列表，选择 Frameveil Camera (Windows Virtual Camera)。
  6. 用完点击关闭输出，或退出帧幕。每次启动默认关闭输出。

播放控制

导入多张图片后设置每张时长，可顺序或随机循环。视频支持速度与进度调整，不输出音轨。

暂停冻结画面；黑屏待机持续发送黑色画面；恢复后继续播放。镜像、裁剪、留边颜色均可调整。

遇到问题

找不到设备：先开启帧幕，再刷新设备列表，必要时重启会议客户端。

打开失败：确认选择了同名原生设备，通过接收自检和诊断 / 日志检查。管理员授权取消时，重新安装组件。
